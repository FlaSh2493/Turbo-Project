# Interaction Principles

AFDS는 사용자의 행동에 대해 **일관되고 예측 가능한 시각적 피드백**을 제공합니다.
모든 인터랙티브 요소(버튼, 링크, 폼 입력창 등)는 아래의 상태 규칙을 따릅니다.

## 1. State Definition (상태 정의)

각 상태는 색상, 투명도, 테두리 등을 통해 명확히 구분되어야 합니다.

### Hover (마우스 오버)

- **목적**: "누를 수 있음"을 인지시킴.
- **스타일 규칙**:
  - **배경색 있는 요소**: 밝기(Lightness)를 **10%** 어둡게 조정.
  - **텍스트/아웃라인 요소**: 배경색을 `surface-subtle` 또는 `brand-subtle`로 옅게 채움.
  - **변화 속도**: `duration-fast` (150ms) 적용.
  - _금지 사항_: 레이아웃이 변경되거나(크기 변화), 주변 요소를 밀어내는 효과.

### Active (클릭/터치 중)

- **목적**: "눌렸음"을 물리적으로 느끼게 함.
- **스타일 규칙**:
  - **배경색**: Hover 상태보다 더 어둡게 조정.
  - **Scale**: 크기를 **0.98**배로 축소하여 "눌리는 느낌" 제공 (선택 사항).

### Focus (키보드/입력 포커스)

- **목적**: 현재 입력 위치를 명확히 표시 (접근성 필수).
- **스타일 규칙**:
  - **Focus Ring**: 요소 외부에 `2px` 두께의 `brand` 색상 링(Ring)을 표시.
  - **Offset**: 요소와 링 사이에 `2px` 간격(Offset)을 두어 배경과 구분.
  - **Mouse Focus**: 마우스 클릭으로 인한 포커스에는 링을 숨길 수 있음 (`:focus-visible` 사용).

### Disabled (비활성화)

- **목적**: 상호작용 불가능함을 표시.
- **스타일 규칙**:
  - **Opacity**: 전체 투명도를 **0.5** (50%)로 낮춤.
  - **Cursor**: `not-allowed` 커서 표시.
  - **Interaction**: 모든 `hover`, `active` 스타일 및 이벤트 제거 (`pointer-events: none`).
  - _예외_: 텍스트 가독성을 위해 Opacity 대신 `fg-muted` 색상을 사용할 수 있음.

## 2. Feedback Timing

- 사용자의 액션에 대한 반응은 **100ms 이내**에 시작되어야 합니다.
- 비동기 작업(API 호출 등)이 1초 이상 걸릴 경우, 반드시 **로딩 인디케이터(Spinner/Skeleton)**를 표시합니다.
