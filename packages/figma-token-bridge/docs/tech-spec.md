# figma-token-bridge Technical Specification

## Overview

`figma-token-bridge`는 Figma Variables와 코드 사이의 **범용 디자인 토큰 변환 레이어**입니다.
W3C DTCG(Design Tokens Community Group) JSON 포맷을 단일 진실의 원천으로 삼아,
디자인시스템이 사용하는 CSS Variables와 TypeScript 타입을 자동 생성합니다.

## Goals

- Figma Variables ↔ 코드 디자인 토큰 **일원화**
- **DTCG JSON**을 중간 포맷으로 사용 (수작업 동기화 제거, 추후 자동화 확장 가능)
- 특정 디자인시스템에 **종속되지 않는** 범용 엔진 (config 주입 방식)
- **외부 라이브러리 충돌 없는** CSS namespace 격리
- CLI + API 양방향 지원

## Non-Goals

- 컴포넌트 단위 토큰 관리 (컴포넌트 토큰은 각 디자인시스템이 직접 관리)
- Figma REST API 자동 연동 (v1 범위 외, v3 로드맵)
- 기존 Tailwind 기본값 사용 (전부 AFDS 커스텀 값으로 override)

## Token Architecture

### 3-Tier 구조

```
Tier 1: Primitive  →  @theme (Tailwind 클래스 생성 + CSS 변수)
Tier 2: Semantic   →  :root  (CSS 변수만, 클래스 없음)
Tier 3: Dark       →  .dark  (Semantic 토큰 override, selector 설정 가능)
```

Dark tier는 Semantic CSS 변수명을 **재정의**하는 방식으로 override를 구현합니다.
alias는 항상 primitive CSS 변수를 참조하며, `.dark` 클래스에서 primitive를 재정의하면
semantic에 자동 반영됩니다.

### Figma Variables → DTCG JSON → CSS/TS 흐름

```
Figma Variables
    ↓ (플러그인 export / 추후 REST API)
DTCG JSON
    tokens.primitive.json   ← 편집 대상 (단일 진실의 원천)
    tokens.semantic.json    ← 편집 대상 (단일 진실의 원천)
    tokens.dark.json        ← 편집 대상 (단일 진실의 원천)
    ↓ figma-token-bridge generate
    primitive.css           ← generated (편집 금지)
    semantic.css            ← generated (편집 금지)
    dark.css                ← generated (편집 금지)
    tokens.ts               ← generated (편집 금지)
```

## DTCG JSON Format

W3C DTCG 스펙 기반. 파일당 하나의 tier.

```jsonc
// tokens.primitive.json
{
  "$description": "AFDS Primitive Tokens - raw values, do not use directly in components",
  "color": {
    "gray": {
      "50": { "$value": "#fafafa", "$type": "color" },
      "500": { "$value": "#888888", "$type": "color" },
      "700": { "$value": "#3d3d3d", "$type": "color" },
    },
    "primary": {
      "500": { "$value": "#556af9", "$type": "color" },
      "600": { "$value": "#4458e0", "$type": "color" },
    },
  },
  "spacing": {
    "1": { "$value": "4px", "$type": "dimension" },
    "4": { "$value": "16px", "$type": "dimension" },
  },
  "radius": {
    "lg": { "$value": "8px", "$type": "dimension" },
    "full": { "$value": "9999px", "$type": "dimension" },
  },
}
```

```jsonc
// tokens.semantic.json
{
  "$description": "AFDS Semantic Tokens - use these in components",
  "color": {
    "surface": { "$value": "{color.white}", "$type": "color" },
    "fg": { "$value": "{color.gray.700}", "$type": "color" },
    "brand": { "$value": "{color.primary.500}", "$type": "color" },
  },
}
```

### Alias 해석 전략

**런타임 참조 (var() 체인)** 방식을 사용합니다.

```
{color.primary.500}  →  var(--color-afds-primary-500)
```

- 빌드타임에 값을 인라인하지 않음
- CSS 런타임에서 참조를 따라 해석
- 다크모드 동작 보장: `.dark` 클래스에서 primitive override 시 semantic에 자동 반영
- alias는 tier에 관계없이 항상 primitive CSS 변수를 가리킴

## Naming Convention

### CSS Variable 패턴

| Tier                | JSON path        | CSS Variable            | Tailwind Class           |
| ------------------- | ---------------- | ----------------------- | ------------------------ |
| Primitive / color   | `color.gray.500` | `--color-afds-gray-500` | `bg-afds-gray-500`       |
| Primitive / spacing | `spacing.4`      | `--spacing-afds-4`      | `p-afds-4`, `gap-afds-4` |
| Primitive / radius  | `radius.lg`      | `--radius-afds-lg`      | `rounded-afds-lg`        |
| Primitive / shadow  | `shadow.sm`      | `--shadow-afds-sm`      | `shadow-afds-sm`         |
| Semantic / color    | `color.brand`    | `--afds-color-brand`    | —                        |
| Dark / color        | `color.surface`  | `--afds-color-surface`  | —                        |

### 변환 규칙

```
primitive: --{tailwind-category}-{namespace}-{path-kebab}
  color.gray.500  →  --color-afds-gray-500
  spacing.4       →  --spacing-afds-4

semantic:  --{namespace}-{category}-{path-kebab}
  color.brand     →  --afds-color-brand
  color.fg-muted  →  --afds-color-fg-muted

dark:  --{namespace}-{category}-{path-kebab}  (semantic과 동일한 변수명 재정의)
  color.surface   →  --afds-color-surface
```

## CSS Output

### primitive.css (@theme 블록)

```css
/* generated by figma-token-bridge — DO NOT EDIT */
@theme {
  --color-afds-white: #ffffff;
  --color-afds-gray-500: #888888;
  --color-afds-primary-500: #556af9;
  --spacing-afds-4: 16px;
  --radius-afds-lg: 8px;
}
```

### semantic.css (:root 블록)

```css
/* generated by figma-token-bridge — DO NOT EDIT */
:root {
  --afds-color-surface: var(--color-afds-white);
  --afds-color-fg: var(--color-afds-gray-700);
  --afds-color-brand: var(--color-afds-primary-500);
}
```

### dark.css (selector 블록)

```css
/* generated by figma-token-bridge — DO NOT EDIT */
.dark {
  --afds-color-surface: var(--color-afds-gray-900);
  --afds-color-fg: var(--color-afds-gray-50);
}
```

## TypeScript Output

```ts
// generated by figma-token-bridge — DO NOT EDIT
export const PrimitiveColorSchema = z.enum(['afds-white', 'afds-gray-500', ...])
export type PrimitiveColor = z.infer<typeof PrimitiveColorSchema>

export const SemanticColorSchema = z.enum(['surface', 'fg', 'brand', ...])
export type SemanticColor = z.infer<typeof SemanticColorSchema>

export function semanticColor(token: SemanticColor): string {
  return `var(--afds-color-${token})`
}
```

## Config Interface

```ts
import { defineConfig } from 'figma-token-bridge'

export default defineConfig({
  namespace: 'afds', // /^[a-z][a-z0-9-]{0,63}$/

  tiers: {
    primitive: {
      source: './tokens/tokens.primitive.json',
      output: './tokens/primitive.css',
      tailwind: true, // @theme 블록 생성
    },
    semantic: {
      source: './tokens/tokens.semantic.json',
      output: './tokens/semantic.css',
    },
    dark: {
      source: './tokens/tokens.dark.json',
      output: './tokens/dark.css',
      selector: '.dark', // 기본값: '.dark'
    },
  },

  typescript: {
    output: './tokens.ts',
    zod: true,
  },
})
```

## Validation Rules

| 코드   | 레벨    | 조건                                                                  |
| ------ | ------- | --------------------------------------------------------------------- |
| `E001` | error   | `$type` 누락                                                          |
| `E002` | error   | 허용되지 않은 `$type` 값                                              |
| `E003` | error   | alias 참조 대상 없음 (`{color.xxx}`)                                  |
| `E004` | error   | 순환 참조                                                             |
| `E005` | error   | JSON 파싱 실패                                                        |
| `E006` | error   | source 파일 없음                                                      |
| `E007` | error   | CSS injection 위험 문자 (`$value`에 `;`, `{`, `}`, `@`, `/*`, `url(`) |
| `E008` | error   | output 파일 쓰기 실패 (권한 없음 또는 path traversal 차단)            |
| `E009` | error   | 유효하지 않은 namespace                                               |
| `W001` | warning | dark tier에서 미존재 semantic 토큰 override                           |
| `W002` | warning | `$description` 누락                                                   |
| `W003` | warning | primitive에서 alias 참조 사용                                         |
| `W004` | warning | 미사용 primitive 토큰 (validate에서만)                                |
| `I001` | info    | 미사용 primitive 토큰 (--verbose)                                     |
| `I002` | info    | 동일한 값을 가진 토큰 중복                                            |

```
✗ [E003] tokens.semantic.json → color.brand
  Alias '{color.primary.999}' not found in primitive tokens.
  Available: color.primary.50, color.primary.500, color.primary.600
```

## Security

### CSS Injection 방어

`$value`에 `;`, `{`, `}`, `\n`, `\r`, `@`, `/*`, `url(` 포함 시 E007 에러로 중단.

```typescript
const CSS_UNSAFE_RE = /[;{}\n\r@]|\/\*|url\s*\(/i
```

### Path Traversal 방어

`assertWithinBase()`로 output 경로가 config 디렉토리 내에 있는지 검증.
`fs.realpath()`로 symlink resolve 후 base directory 포함 여부 확인.

### TypeScript Injection 방어

`escapeTsString()`으로 `\`, `'`, `` ` ``, `${` 이스케이프 처리.

### Namespace 검증

`/^[a-z][a-z0-9-]{0,63}$/` 패턴으로 CSS selector/variable 안전성 보장.

## CLI Interface

```bash
# 기본 실행 (token-bridge.config.ts 자동 탐색)
npx figma-token-bridge generate

# config 직접 지정
npx figma-token-bridge generate --config ./custom.config.ts

# 검증만 실행
npx figma-token-bridge validate

# CI 모드 (경고를 에러로 처리)
npx figma-token-bridge generate --strict

# 상세 출력
npx figma-token-bridge generate --verbose
```

## API Interface

```ts
import { generate, validate, defineConfig } from 'figma-token-bridge'

const config = defineConfig({ namespace: 'afds' /* ... */ })

// 검증
const result = await validate(config)
if (!result.ok) console.error(result.errors)

// 생성
await generate(config)
```
