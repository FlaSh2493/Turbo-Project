# QA 시나리오

사용자가 이 시나리오대로 화면을 직접 본다. 언제 어디에 쓰는지는 `[BASE-REQ]`를 따른다. 이 파일은 쓰는 법만 다룬다.

## [QA-FORM] 양식

```markdown
## QA 시나리오

- 대상: <로컬 | URL>
- 계정/역할: <어떤 계정으로 보는지>

### 흐름

1. <사용자가 하는 일>

### 수락 기준

- <화면에서 눈으로 확인할 수 있는 결과>
```

## [QA-WRITE] 쓰는 법

- 흐름은 사용자가 하는 일로 쓴다. 셀렉터, 클래스명, 버튼 위치는 쓰지 않는다.
- 수락 기준은 요구사항 출처에서 가져오고, 화면에서 판정할 수 있는 문장으로 쓴다.
- 권한·빈 값·실패 응답처럼 분기가 있으면 분기마다 흐름을 나눈다.
- 이번 변경이 아니어도 바뀐 코드를 쓰는 화면과 이동 경로는 회귀 흐름으로 따로 적는다.
