# 문서

플랜을 쓸지는 `[BASE-WORK]` 1단계에서 정한다. 이 파일은 쓰는 법만 다룬다.

| 문서      | 위치          | 담는 것                                | 수명                        |
| --------- | ------------- | -------------------------------------- | --------------------------- |
| 변경 요청 | Jira 이슈     | 이번에 무엇을 바꾸는가                 | 변경 하나                   |
| 플랜      | `docs/plans/` | 이번 변경의 설계·구현 계획·QA 시나리오 | 작업이 끝나면 고치지 않는다 |

## [DOC-PLAN] 플랜

- 파일 이름은 `<티켓 키>-<slug>.md`, 티켓이 없으면 `<date>-<slug>.md`다.
- 출처, 현재 상태, 영향 분석(영향받는 화면과 이동 경로), 구현 단계, 검증 순서, QA 시나리오로 쓴다.
- 현재 동작은 코드와 테스트로 판단한다. 지난 플랜을 모아 추론하지 않는다.
