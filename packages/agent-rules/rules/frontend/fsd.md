# FSD 구조

## [FSD-LAYER-DIR] 레이어 방향

- 위 레이어만 아래 레이어를 가져다 쓴다.
- 레이어를 늘리기 전에 사람에게 묻는다. 늘리면 린트 설정과 경로 별칭도 같이 고친다.

## [FSD-BARREL] 슬라이스 밖에서는 배럴로만 가져온다

- 슬라이스 밖에서는 `index.ts`로만 가져온다. 배럴에는 밖에서 쓰는 것만 올린다.
- 같은 슬라이스 안에서는 상대경로로 가져온다.

## [FSD-NO-CROSS] 같은 레이어 슬라이스끼리 가져다 쓰지 않는다

- 상위 레이어에서 props로 조합한다. drilling이 과해지면 공통 부분을 하위 레이어로 내린다.
- 하위 레이어로는 두 슬라이스 이상이 실제로 쓸 때만 올린다.

## [FSD-SPLIT] 파일이 섞이면 나눈다

- 데이터 요청, 부수효과(router·modal·toast), 상수, 순수 변환 함수, 깊은 JSX 중 셋 이상이 한 파일에 섞이면 나눈다.
- 같은 JSX가 두 곳 이상 반복되면 추출한다.
