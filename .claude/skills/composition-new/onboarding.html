빨강 · 멈춤

규칙을 어겨 제출이 막힙니다. Claude가 고칩니다.

  • 디자인 토큰 대신 색·크기를 직접 적음 (예: #FF5733, 13px)
  • 파일 구조·이름 규칙 위반
  • 테스트 실패
노랑 · 주의

막지는 않지만 새로 만든 코드에 있으면 PR 화면에 노란 표시가 뜹니다. Claude가 토큰으로 바꿉니다.

  • Tailwind 기본 색·간격·모서리 (예: text-gray-500, p-4, rounded-lg)
  • 맞는 토큰이 없으면 PR에 그렇게 적어 둡니다

검사를 모두 통과했습니다. 이제 당신이 눈으로 비교할 차례예요.
