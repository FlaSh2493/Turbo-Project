# 코드 컨벤션

새로 쓰거나 고치는 코드에 적용한다. 기존 코드를 맞추려고 따로 고치지 않는다.

## [CODE-EFFECT] useEffect는 마지막 수단이다

- 같은 문제를 푼 코드가 레포에 있으면 그 방식을 따른다.
- 계산할 수 있는 값은 렌더 중에 계산하고, 사용자 동작은 이벤트 핸들러에서, 서버 데이터는 쿼리 훅으로 처리한다. effect로 하지 않는다.
- 렌더 바깥 시스템과의 동기화(리스너, 옵저버, 타이머, 구독)에는 effect를 쓰고 cleanup을 반환한다. `useRef` 플래그로 effect를 흉내 내지 않는다.
